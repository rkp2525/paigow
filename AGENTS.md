# Project instructions

## Pull request merge approval

- Agents may open pull requests without requesting merge approval.
- Every merge requires the user's explicit approval for that specific PR. Never merge a PR on your own.
- Before merging, present the specific PR URL and the changes being merged, then wait for the user's explicit approval. General instructions to implement, finish, ship, deploy, or continue are not merge approval.
- Approval for one PR does not authorize any other PR. If the proposed changes change after approval, obtain approval again before merging.
- Do not enable auto-merge or bypass this approval requirement through direct pushes to the default branch, local branch merges, APIs, or other mechanisms.
